## 🌟 Features Overview

### 🎮 Game Modes
| Classic Modes | Custom / Special Modes |
| :--- | :--- |
| • All Original Game Modes<br>• Ladder Mode | • Infected / Vamper<br>• Turbo / Skill Map Mode<br>• Spy Mode / Gun Game<br>• Ghost Mode |

### 💻 Client Features
| Category | Features Included |
| :--- | :--- |
| **Interface & Quality** | • Unicode support (UTF-8)Support for language IMEs such as Chinese, Japanese, and Korean<br>• Multi Language & New Chat / Chat Emoji<br>• HUD conversion & Focus mode (respawn, PMs, matchmaking) |
| **Visual & Effects** | • Discord Status & Voice Chat<br>• Custom Rank Color (UGrande) & Tag Name<br>• Dash Color, Sword Trail, Spark Shot & Effect Hit<br>• Dmg Counter, Show PFS, Kill Feed, Kill Streak, Float Damage<br>• Outline Character Color |
| **Gameplay & Utility** | • New Antilead System & New Custom Encrypt MRS<br>• Vote Map, Room Tags, Camera Distance & FOV<br>• Multiple Shop types (Cash & Ladder)<br>• Sort & categorize `zitem.xml`, `zitem_cash`, `zitem_event`, `zitem_medal`<br>• Create a Clan with just 1 person<br>• Create a room with a room tag selection |

### 🛡️ Easy Anti-Cheat (EAC)
> [!NOTE]
> I'm not using the EAC branch right now because you might not be familiar with the way to install it integrated into the source. However, I'm not removing it—if you know how to use it, enable `_EAC` and enjoy!

### ⚡ RealSpace2 Engine Tweaks
- Minor rendering performance tweaks.
- Support and recognition of new GPU lines such as **Intel Arc / Iris XE**.
- Extended memory limit.

###  Mint2
- Refactor some code to align with the new UI
